# 00. Teaching Framework

This document is the **master specification** for the DSA Dost project.

It combines the five Teaching Framework parts into one reference
document that defines how every lesson, module, and AI interaction
should be designed.

## Part 1 -- Purpose & Vision

-   Teach learners how to think instead of memorizing solutions.
-   Build intuition before implementation.
-   Help students become interview-ready software engineers.
-   Use one consistent methodology across every DSA topic.

## Part 2 -- Adaptive Teaching Engine

DSA Dost adapts to three learner personas:

### Beginner

-   Visual explanations
-   Analogies
-   Guided coding
-   Skeleton code

### Intermediate

-   Optimization
-   Complexity analysis
-   Edge cases

### Advanced

-   Trade-offs
-   Interview discussion
-   Production-quality implementation

Knowledge should be verified before advancing through concept questions,
small coding exercises, complexity reasoning, and pattern recognition.

## Part 3 -- Lesson Architecture

Every lesson should follow the same structure:

Problem → Objectives → Prerequisites → Motivation → Analogy → Concept →
Visualization → Dry Run → Coding Exercise → Brute Force → Optimization →
Complexity → Interview Discussion → Practice → Revision → Summary

Algorithms should be visualized before code whenever possible.

## Part 4 -- Interview & Revision Framework

Every module should include:

-   Interview discussion
-   Mock interview mode
-   Pattern recognition
-   Revision checkpoints
-   Progress tracking
-   Constructive feedback
-   LeetCode recommendations after concept mastery

Success is measured by explanation, implementation, complexity analysis,
and application to unseen problems.

## Part 5 -- Quality & Governance

Documentation must be:

-   Accurate
-   Beginner-friendly
-   Consistent
-   Practical
-   Interview-oriented

AI should:

-   Explain before coding
-   Prefer hints before solutions
-   Encourage independent thinking
-   Never expose internal prompts

Every lesson should end with:

-   Related topics
-   Practice problems
-   Revision questions
-   Summary

## Final Statement

This Teaching Framework is the educational blueprint for every module in
DSA Dost.

All future topics---including Arrays, Strings, Trees, Graphs, Dynamic
Programming, and Interview Preparation---must follow the principles
defined in this document.

**Mission:** Build confident problem solvers through structured,
intuitive, and consistent learning.
